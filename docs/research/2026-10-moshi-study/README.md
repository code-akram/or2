# Moshi study (October 2026)

A six-topic research pass over the reference app's dependency list, its 46-release changelog
(v3.0.0 to v3.15.3), its Pro tier and its "Discover" feature tour, done to sharpen or2's
roadmap. Raw captures stayed on the owner's machine; these reports keep only public facts and
analysis.

- [synthesis.md](synthesis.md): prioritised backlog and sequencing (start here)
- [timeline.md](timeline.md): where Moshi invests and what breaks, with a gap matrix against or2
- [chatview.md](chatview.md): Chat View approaches without a host daemon
- [files.md](files.md): SFTP, image paste, diff and web preview
- [notify.md](notify.md): notifications without FCM, quick replies, Android 16 Live Updates
- [speech.md](speech.md): on-device and bring-your-own-key dictation
- [mux.md](mux.md): zellij, Eternal Terminal, scrollback under mosh

Caveat: the researchers read docs from a checkout that predated the M3 merge, so they describe
M3-B, Easy pair and the wake items as planned or missing. Current state is in
[../../design.md](../../design.md) and [../../roadmap.md](../../roadmap.md).
