# or2 v0.1.8

The terminal draws block art, boxes, Claude Code's status arrows and Powerline itself, pixel-exact on the
cell grid, instead of through the phone's fonts. Same FFI API 23, no database migration, daemon,
re-pairing or host authorization change. Updates previous signed releases in place, preserving hosts and
Keystore-bound keys. Android 14 or later, arm64; versionCode 15.

## What's new

- **Claude Code looks like it does on a desktop terminal.** Its mascot is solid, without the seams the
  phone's fonts left between cells; the permission-mode arrows `⏵⏵` (shift+tab) show as arrows rather than
  two hollow boxes; and its `⏺` bullets are dots in the text colour rather than colour emoji.
- **Box drawing and block elements are drawn, not typeset.** Light, heavy, double, dashed, rounded and
  diagonal lines (U+2500–257F) and every block element (U+2580–259F: halves, eighths, quadrants, shades)
  are whole-pixel shapes, so borders, panels, tables, progress bars and block art join without gaps,
  at every pinch size. The media symbols `⏴⏵⏶⏷⏸⏹⏺` and Powerline separators (U+E0B0–E0B7) are drawn too;
  no font on the phone has the arrows or Powerline. The Home thumbnails draw the same shapes.
- Other symbols still come from Android's fallback fonts: `⎿`, `✻` and `✔` show, but their size and
  baseline can differ a little from the text. A bundled terminal font is a possible later step.

## Install

**The app.** Download `or2-v0.1.8.apk` and install over the previous signed release. Do not uninstall or
clear the daily app. SHA-256:

```text
87bf7708aa4323113ba2a0e6eda1ef1cd358c4296c03473cac8537cecf40b6e3  or2-v0.1.8.apk
```

Check with `sha256sum or2-v0.1.8.apk`. Debug APKs use a different signing key and cannot update the signed app.

**`or2-pair`.** Existing host installations keep working; no re-pairing is needed. This release changes
its version, not pairing behavior. Linux x86_64/aarch64 and macOS Intel/Apple silicon binaries are available
through the checksum-verifying installer:

```sh
curl -fsSL https://raw.githubusercontent.com/code-akram/or2/main/scripts/install-or2-pair.sh | sh
```

From source: `cargo install --git https://github.com/code-akram/or2 --tag v0.1.8 or2-pair --locked`.

## Verified, and still untested

- **1,087 Rust workspace tests**, no failures or ignored, with sshd, tmux, mosh and herdr required (Rust is
  unchanged since v0.1.7 apart from the version); formatting, Clippy with warnings denied, both generator
  checks and `demo-gif --check` pass.
- **683 JVM tests** (eight new for the sprite geometry: every line leaves a cell where its neighbour enters,
  double-line junctions keep their gaps, blocks partition the cell, the mascot's row is one solid bar), no
  failures, errors or skips; debug, device-test and signed release builds and both lints pass, with all 183
  Gradle tasks rerun. The host native contract reports 0.1.8/API 23. The release APK is signed by the same
  certificate as v0.1.7 (SHA-256 `1418c4aa…a2a2`) and reports versionCode 15, versionName 0.1.8.
- **Device suite on the separate device-test app: 182 cases, one failure.** Two new cases check the mascot
  and `⏵⏵` pixel by pixel and capture the sprites on the phone's hardware renderer (reviewed zoomed in); the
  48 terminal device tests pass, with unchanged frame timings. The failure is an existing composer check
  (`closingTheComposerGivesTheKeysBackToTheTerminal`: the composer was still shown after toggling it twice);
  it then passed eight of nine runs alone and its class passed twice. The composer and that test are
  unchanged since v0.1.7; the same intermittent composer check is recorded in earlier cycles. The demo and
  notification-permission cases are skipped by design. The daily app's version and update time stayed
  unchanged; the test packages were removed afterwards.
- Linux `dist --expect-version 0.1.8` passes: both static, stripped architectures and checksums; x86_64 runs,
  aarch64 is format-checked only. macOS binaries are built on macOS by the release workflow.
- **Published release verified:** tag `v0.1.8`; [run 37958819166](https://github.com/code-akram/or2/actions/runs/37958819166)
  built Linux/macOS and published. All six public assets downloaded: the four binaries match `SHA256SUMS` and
  their formats (static stripped Linux ELF, Mach-O per architecture); the public APK matches the SHA-256 above
  and the v0.1.7 signing certificate. The public x86_64 Linux binary reports `or2-pair 0.1.8`, and the installer
  from `main` (identical to the repository's) installed a checksum-matching `or2-pair 0.1.8` into a temporary
  directory, without touching any host installation.
- **Owner QA before release:** a signed candidate with the same change (0.1.7 / versionCode 14) was installed
  in place on the owner's phone; the owner approved it for release ("beautiful work").
- **Still owner-deferred:** mobile data, Wi-Fi handover and unplugged/Doze acceptance.
