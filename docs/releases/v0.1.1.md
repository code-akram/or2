or2 v0.1.1 is a patch release: terminals open at once on every host, agent notifications arrive, a swipe scrolls the
program you are looking at, links open with a tap, and the terminal screen and `or2-pair` got a careful
redesign. It installs over v0.1.0 and keeps your hosts and keys.

## What's new

- **Instant opens.** Under Auto, a tmux or herdr terminal opens over SSH at once and switches to mosh in the
  background as soon as mosh's UDP gets through (the badge flips from SSH to Mosh). A host whose UDP is dropped
  no longer costs seconds of waiting; it says so once on its page, and is checked again, unseen, after five
  minutes. The capability probe no longer waits for herdr's session list.
- **Agent notifications.** One notification when a herdr agent needs input or finishes, none for the pane on
  screen; a tap opens that pane. On by default for the hosts shown in the inbox, with a switch in Settings.
- **Scrolling that follows the program.** A swipe sends wheel events to programs that track the mouse, scrolls
  tmux through copy mode and herdr through its own scroll otherwise, and never walks shell history. A round
  button returns to the bottom, and typing while scrolled up waits until the pane is back at the bottom, so no
  key lands in copy mode.
- **Tap links** (http and https, OSC 8 hyperlinks, URLs wrapped across lines), and **copy from the host**: text
  copied on the host with OSC 52 (tmux, herdr, Neovim) reaches the phone's clipboard. On by default, with a
  switch in Settings; the host can never read the phone's clipboard.
- **Gestures and keyboard shortcuts.** Swipe for the next or previous tmux window or herdr tab, two fingers for
  panes and sessions; `Ctrl+Shift` shortcuts on a hardware keyboard (`/` shows them).
- **A redesigned terminal top.** The minimise and sessions discs as a pair, the title centred (host, then the
  target), a slim drag handle, and the transport pill, which also shows how long a quiet mosh link has been
  silent. Status lines are one compact strip that never covers the terminal. The arrow pad floats with no panel
  behind it.
- **Home.** A host card opens the host's page; its `>_` button opens the session picker straight over Home,
  connecting the host first when needed. Opening a tmux or herdr session that is already open brings it to the
  front. Close session ends and removes a terminal in one tap. "Skip" in the picker is now "Shell". A Settings
  screen joins Home.
- **`or2-pair`.** Its output and the installer's are one calm rail from start to finish, in the spirit of
  clack: a symbol and colour per kind of line, fixes under their check, the code prompt and the QR on the rail,
  an explicit end. Colour only on a terminal (`NO_COLOR` respected), an ASCII rail outside a UTF-8 locale. On
  macOS it reads the application firewall and prints the commands that allow `mosh-server` when it would be
  blocked.

Fixes from two external review rounds are in too: no keystroke can be lost while a terminal switches from SSH
to mosh; a `mosh-server` is recorded on disk before mosh connects, so one is never left running after the app's
process dies; notifications are reconciled after the process dies and a notification tap survives Android
restoring the app; tmux session moves act only on the terminal's own client.

## Install

**The app.** Download `or2-v0.1.1.apk` and install it over v0.1.0 (Android 14 or later, arm64); your hosts and
keys stay. It is signed with the or2 release key. SHA-256 of the APK:

```text
APK_SHA256  or2-v0.1.1.apk
```

Check it with `sha256sum or2-v0.1.1.apk` before installing. A debug build of or2 is signed with a different key:
uninstall it first (that deletes its hosts and Keystore-bound keys) and pair the hosts again.

**`or2-pair` on a host** (Linux x86_64 or aarch64, static; macOS Intel or Apple silicon), into `~/.local/bin`,
no `sudo`; running it again updates it:

```sh
curl -fsSL https://raw.githubusercontent.com/code-akram/or2/main/scripts/install-or2-pair.sh | sh
or2-pair
```

The script installs the binary for your OS and CPU from the latest release, checks it against the release's
`SHA256SUMS`, runs it once and only then puts it in place; `--version v0.1.1` pins this release. From source:
`cargo install --git https://github.com/code-akram/or2 --tag v0.1.1 or2-pair --locked`.

## Verified, and still untested

- **Verified on the owner's phone** (OnePlus 10 Pro, Android 16): this build installed over v0.1.0; Easy pair
  with a Mac on the LAN (the macOS `or2-pair` from the one-liner) and with a host reached over its public
  address; instant opens and the switch to mosh on the Mac; the new top bar, arrow pad and picker. The
  device suite passes (137 tests; the two that post notifications skip, because the test phone refuses to grant
  the permission to a test build).
- **Still untested**: mobile data, the Wi-Fi to mobile data handover, and background runs while the phone is
  unplugged (Doze); so the v0 acceptance test (10 minutes in the background over mobile data, then back to the
  same pane) is still open. A posted agent notification has been checked by tests, not yet watched end to end on
  the phone. The macOS firewall check reads real `socketfilterfw` output from one Mac only.
- **Limits that remain**: tmux older than 2.6 gets no session-switching swipe (windows and panes work); mosh
  keeps no scrollback of its own; a hardware keyboard bypasses the IME; arm64 Android 14+ only; not on F-Droid
  yet. See the [v0.1.0 notes](https://github.com/code-akram/or2/blob/v0.1.1/docs/releases/v0.1.0.md) for the
  rest, and the [changelog](https://github.com/code-akram/or2/blob/v0.1.1/CHANGELOG.md).
