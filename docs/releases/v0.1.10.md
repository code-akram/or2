# or2 v0.1.10

M4: read what scrolled away, wake a sleeping host, and answer Claude Code's permission prompts from the
notification. FFI API 24; the database migrates to schema 5 on first open (two new host fields, nothing
removed). No daemon, re-pairing or host authorization change. Updates previous signed releases in place,
preserving hosts and Keystore-bound keys. Android 14 or later, arm64; versionCode 19.

## What's new

- **History sheet.** Terminals → **History** on a tmux or herdr terminal opens the target's last 2,000 lines, read
  from the host as plain text, selectable, with **Copy all**. It never moves the pane, so the view on your other
  screens is unchanged. Under mosh, which keeps no local history, a small **History** chip appears when you swipe
  up past the top.
- **Wake a sleeping host.** A host can have its MAC address and a **Wake probe** switch. **Wake** in its options
  sends the Wake-on-LAN magic packet on the local network, knocks on SSH (which wakes a Mac through a Bonjour Sleep
  Proxy such as an Apple TV or HomePod) and keeps retrying for 30 s; with the probe on, every connect of that host
  knocks first. A MacBook with its lid closed on battery may not wake at all; or2 says so instead of retrying forever.
- **Approve or Deny from the notification.** When Claude Code asks for permission, its notification gets **Approve**
  and **Deny**. Both need the phone unlocked. Just before answering, or2 checks through herdr that the same prompt
  is still showing, with "1. Yes" highlighted and Claude Code in the foreground, then presses Enter or Esc. If
  anything changed it does nothing and says "The prompt changed. Open the pane." Claude Code only for now: other
  agents' prompts can't yet be told apart from questions reliably.
- **Agent summary.** The connection notification reads like "1 needs input · 2 working". While an agent needs
  input it asks Android 16 to show it as a Live Update.
- **Settings:** **Keep screen on** while a terminal is visible (off by default) and **Reopen the last terminal on
  launch** (on by default).

## Install

**The app.** Download `or2-v0.1.10.apk` and install over the previous signed release. Do not uninstall or
clear the daily app. SHA-256:

```text
d9e272dd93c5fb34be5b89cfff1702bec20f9977f73e9718cf18c7a450cf07ea  or2-v0.1.10.apk
```

Check with `sha256sum or2-v0.1.10.apk`. Debug APKs use a different signing key and cannot update the signed app.

**`or2-pair`.** Existing host installations keep working; no re-pairing is needed. This release changes
its version, not pairing behavior. Linux x86_64/aarch64 and macOS Intel/Apple silicon binaries are available
through the checksum-verifying installer:

```sh
curl -fsSL https://raw.githubusercontent.com/code-akram/or2/main/scripts/install-or2-pair.sh | sh
```

From source: `cargo install --git https://github.com/code-akram/or2 --tag v0.1.10 or2-pair --locked`.
