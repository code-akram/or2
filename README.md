# or2

A free, open-source Android client for SSH and mosh, built for driving coding agents that run in
tmux or herdr on your own machines.

Status: M0 prototypes, a buildable M1 Rust/Android scaffold and the tested M1 shared contracts
(key material, host-key trust, session lifecycle, terminal frames and input).
SSH sessions and terminal rendering are not implemented in the app yet.
See [the design](docs/design.md), [contracts](docs/contracts.md) and [build instructions](docs/build.md).
