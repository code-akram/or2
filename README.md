# or2

A free, open-source Android client for SSH and mosh, built for driving coding agents that run in
tmux or herdr on your own machines.

Status: M0 prototypes and a buildable M1 Rust/Android scaffold with a tested UniFFI bridge.
SSH sessions and terminal rendering are not implemented in the app yet.
See [the design](docs/design.md) and [build instructions](docs/build.md).
