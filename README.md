# or2

A free, open-source Android client for SSH and mosh, built for driving coding agents that run in
tmux or herdr on your own machines.

Status: M1 complete. The Android app stores hosts and biometric-protected SSH keys, confirms host
keys, and opens a usable SSH terminal (Ghostty engine, Canvas renderer, soft-keyboard input).
Mosh, tmux/herdr and background sessions are later milestones.
See [the design](docs/design.md), [contracts](docs/contracts.md) and [build instructions](docs/build.md).
